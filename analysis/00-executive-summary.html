Top 5 risks

  1. Anyone on the internet can obtain master keys. A public page hands out the live DocuSign CLM token; a public lookup can read tables holding integration passwords and keys.
  2. Online payments can be faked or zeroed. The browser sets the BREG checkout price ($0 = Paid); two public web services create 'Completed' payments.
  3. The public can see and change other people's records. Delete or take over other filers' cases, join someone else's business account, read payer, complainant and draft-application data.
  4. Core automation silently skips or drops work. BREG logic skipped beyond 200 records; PVL event batches lost; 48 retired Process Builders run core logic.
  5. Tests don't prove the money code works. Payment tests assert nothing, code behaves differently under test, and a date bug blocks releases from 1 Jan 2027.
